
# Python & Flask Dynamic Web Application

## 📌 Summary
This web application was built as a hands-on learning project to master backend web routing, HTTP request handling, and dynamic template rendering[cite: 1]. It serves as a practical foundation for full-stack Python development, seamlessly bridging server-side logic with user-facing front-end interfaces[cite: 1].

---

## 🛠️️ Technologies Used
- **Backend:** Python, Flask[cite: 1]
- **Frontend & Dynamic Rendering:** HTML5, CSS3, Jinja2 Templating[cite: 1]
- **Version Control & Workflow:** Git, GitHub[cite: 1]
- **Environment:** Python Virtual Environment (`venv`)[cite: 2]

---

## ✨ Key Features
- **Backend Routing:** Dynamic route management and HTTP GET/POST request handling built with Flask[cite: 1].
- **Dynamic Content Rendering:** Uses Jinja2 templates to pass Python variables and state directly into HTML pages[cite: 1].
- **Interactive Forms:** Functional user input forms that process data on the server side[cite: 1].
- **Responsive Layout:** Clean, structured interface designed with custom CSS styling[cite: 1].

---

## 💡 Development Process & Learning Experience
This project was created as a guided learning experience to expand my core programming skills in web development[cite: 1]:
- **Backend Development:** The backend and routing foundation were constructed by following an instructional video tutorial to learn Flask fundamentals and understand how Python connects dynamically to the frontend[cite: 1].
- **Frontend Development:** I designed and wrote approximately **70% of the frontend** independently using structured HTML5 and custom CSS[cite: 1].
- **Leveraging AI:** I utilized AI tools during development to debug errors, correct minor typos, and gain deeper insight into specific Python functions and Flask features I hadn't encountered before.
